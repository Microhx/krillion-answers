# Data notice

This repository publishes a derived dataset of **prompts and accepted answers**
from the browser game *Krillion*.

- **Not official.** This project is not affiliated with, endorsed by, or
  operated by the publisher of Krillion.
- **Source.** Values are derived from publicly reachable reveal data at
  `krillion.io`. Only data that the publisher made publicly available at some
  point is included.
- **Rights.** Prompt wording, answer lists, rarity tiers, scores and any
  descriptive text remain the property of their respective owner. This
  repository claims no ownership over them.
- **Scope.** The published dataset intentionally **excludes** the publisher's
  authored "quip" descriptions. Only short factual fields are distributed:
  mode, date/game id, round, prompt, answer, tier, score, category.
- **Purpose.** Reference, research and personal tooling. Do not use it to
  build a competing product or to misrepresent the official game.
- **Take-down.** If you are the rights holder and want content removed, open an
  issue in this repository and it will be removed promptly.

If you redistribute this dataset, keep this notice with it.
